## Knomo 0.8.9

### Improvements
- Reduced card-feed stutters by caching memo image previews and avoiding unnecessary card and mobile search result rendering.
- Improved image loading by sharing queue and decode state across the card feed, mobile search, and fullscreen preview.
- Improved Markdown image compatibility for nested parentheses, optional titles, angle-bracket paths, escaped brackets, and Obsidian image dimensions.

### Fixes
- Fixed stale or missing card images after local attachments are created, modified, renamed, or deleted.
- Fixed image clicks reparsing card content and potentially opening an image that did not match the rendered preview.
- Fixed multiline memo cards rendering inconsistently between desktop and mobile without changing the stored Markdown.

---

### 改进
- 缓存 Memo 图片预览并减少不必要的卡片流与移动搜索结果渲染，降低浏览卡片时的卡顿。
- 卡片流、移动搜索和全屏预览共享图片加载队列与解码状态，减少重复加载和解码。
- 改进 Markdown 图片语法兼容，支持嵌套括号、可选标题、尖括号路径、转义方括号和 Obsidian 图片尺寸语法。

### 修复
- 修复本地附件创建、修改、重命名或删除后，卡片图片缓存未及时失效的问题。
- 修复点击图片时重新解析卡片内容，可能打开与当前预览不一致图片的问题。
- 修复多行 Memo 卡片在桌面端与移动端显示不一致的问题，同时保持日记中的原始 Markdown 不变。
