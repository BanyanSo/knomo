## Knomo 0.9.0

### Improvements

- Added support for opening the daily note from the Memo card timestamp and card action menu, with line-number hints for positioning.
- Improved card controls, mobile layering, and popover interactions.
- Improved Memo image previews and search result rendering to reduce stuttering while browsing cards.
- Improved Markdown image syntax compatibility, including nested parentheses, optional titles, angle-bracket paths, and Obsidian image size syntax.

### Fixes

- Fixed an issue where closing card or scope popovers on mobile could let the next tap pass through to underlying content.
- Fixed an issue where card image caches were not invalidated promptly after local attachments were created, modified, renamed, or deleted.
- Fixed an issue where clicking an image could re-parse card content and open an image that did not match the current preview.
- Fixed inconsistent display of multi-line Memo cards between desktop and mobile while preserving the original Markdown in the daily note.
- Fixed an issue where percent-encoded local image paths could not be resolved to vault attachments.

---

### 改进
- 新增从 Memo 卡片时间和卡片操作菜单打开日记，支持按行号提示定位。
- 改进卡片控件、移动端层级、弹层交互。
- 改进 Memo 图片预览、搜索结果渲染，降低浏览卡片时的卡顿。
- 改进 Markdown 图片语法兼容，支持嵌套括号、可选标题、尖括号路径、 Obsidian 图片尺寸语法。

### 修复
- 修复移动端卡片/范围弹层关闭时可能把下一次点击透传到底层内容的问题。
- 修复本地附件创建、修改、重命名或删除后，卡片图片缓存未及时失效的问题。
- 修复点击图片时重新解析卡片内容，可能打开与当前预览不一致图片的问题。
- 修复多行 Memo 卡片在桌面端与移动端显示不一致的问题，同时保持日记中的原始 Markdown 不变。
- 修复百分号编码的本地图片路径无法解析到 vault 附件的问题。
