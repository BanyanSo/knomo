## Knomo 0.9.5

### New features

* Added **Record Statistics**, a new statistics page for reviewing weekly, monthly, and yearly memo trends, recording-time distribution, note totals, word totals, reference counts, and daily peaks.
* Added interactive navigation in Record Statistics. You can select a chart bar, tag, or metric to open the matching Memos on desktop or mobile.
* Added a **Common Tags** chart, showing the five most-used tags in the selected range.
* Added selected-range metrics for tagged Memos, untagged Memos, and Memos with images.
* Added per-Memo word statistics, including separate Chinese-character, English-word, and number counts. Markdown syntax, code, image embeds, URLs, block IDs, and generated reference links are excluded from the total.
* Added a settings tool to rebuild a selected monthly archive from Daily Notes while preserving memo IDs and backing up the existing archive first.
* The **All notes** overview metric can now open the complete main card feed directly.

### Improvements

* Improved the loading experience of Record Statistics and reduced layout shifts when switching to the stats page for the first time.
* Improved the Common Tags chart with a dedicated empty state, accessible interactions, consistent bar thickness, and capsule-shaped bars.
* Simplified Record Statistics by removing the earliest/latest record preview modules.
* Improved loading states for “With images”, “With links”, and “Untagged” filter results.
* Optimized the initial mobile filtering experience and image card browsing.
* Added caching for Memo word statistics to reduce repeated Markdown parsing.
* Improved card menu placement so the menu now opens in the direction with more available space.
* Improved localized error and issue messages across memo cards, trash actions, synchronization, repair, and settings maintenance tools.
* Added localized read-only notices to newly created monthly archive files while preserving existing and legacy notices.
* Improved text setting edits so valid changes are saved when the field loses focus or the settings page closes, instead of saving every intermediate keystroke.
* Added English default blacklist tags for Random Reunion, including `temp`, `temporary`, `draft`, and `archived`.
* Improved internal stability and test coverage for Memo Markdown rendering, progressive mobile loading, Random Reunion, and trash actions.

### Fixes

* Fixed historical reference cards losing `sourceMemoId` and reference metadata after an index scan or rebuild. Knomo now restores reference metadata from memo ID aliases or uniquely matched daily-note block targets.
* Fixed historical references being omitted from Record Statistics reference counts and reference navigation results.
* Fixed nested reference recovery so the direct source is preferred over references inside quoted content, while unresolved ordinary block links are not treated as Knomo references.
* Fixed mobile list continuation when the native keyboard inserts a bullet, numbered-list, or task marker without the required trailing space.
* Fixed layout initialization in environments where `ResizeObserver` is unavailable.
* Fixed a mobile popup-dismiss tap that could leave the memo timestamp control focused.

### 新功能

* 新增 **记录统计** 页面，支持按周、月、年查看 Memo 趋势、记录时间分布、笔记总量、字数总量、引用数量、单日峰值等统计信息；支持点击图表柱、标签或统计指标查看对应 Memos，并新增常用标签图表以及“有标签”“无标签”“有图片”等范围统计指标。
* 新增单条 Memo 字数统计，分别计算中文字数、英文单词数和数字数量；统计会排除 Markdown 语法、代码、图片嵌入、URL、block ID 和自动生成的引用链接。
* 设置页新增“重建指定月份归档”工具，可从 Daily Notes 重新生成月度归档，保留 memo ID，并在重建前备份现有归档。

### 改进

* 改进“有图片 / 有链接 / 无标签”筛选结果的加载状态。
* 优化移动端首次筛选和图片卡片浏览体验。
* 改进卡片菜单定位逻辑，菜单会根据可用空间自动选择更合适的展开方向。
* 改进 Memo 卡片、废纸篓操作、同步、修复和设置维护工具中的本地化错误与问题提示。
* 新创建的月度归档文件会写入对应语言的只读提示，同时保留已有提示和旧版提示。
* 改进文本设置项的编辑体验：有效修改会在输入框失焦或关闭设置页时保存，不再保存每个输入过程中的中间值。
* 为“随机回顾”新增英文默认排除标签，包括 `temp`、`temporary`、`draft` 和 `archived`。
* 改进 Memo Markdown 渲染、移动端渐进加载、随机回顾和废纸篓操作的内部稳定性与测试覆盖。

### 修复

* 修复历史引用卡片在索引扫描或重建后丢失 `sourceMemoId` 和引用元数据的问题；现在可通过 memo ID 别名或唯一匹配的日记 block 目标恢复引用关系。
* 修复历史引用未计入记录统计引用数量和引用查看结果的问题。
* 修复多层引用恢复时可能选错来源的问题：现在优先识别当前直接来源，不会把无法确认的普通块链接误判为 Knomo 引用。
* 修复移动端原生键盘插入缺少尾随空格的无序列表、有序列表或任务列表标记时，列表无法正确续写的问题。
* 修复运行环境不支持 `ResizeObserver` 时界面布局无法初始化的问题。
* 修复移动端关闭弹层时，受抑制的点击可能让 Memo 时间控件保持聚焦的问题。
