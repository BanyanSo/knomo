## Knomo 1.0.1

### New features

* Added **Record Statistics**, a new statistics page for reviewing weekly, monthly, and yearly memo trends, recording-time distribution, note totals, word totals, reference counts, daily peaks, the five most-used tags, and selected-range metrics for tagged Memos, untagged Memos, and Memos with images. You can select a chart bar, tag, or metric to open the matching Memos, or use **All notes** to open the complete main card feed on desktop or mobile.
* Added per-Memo word statistics, including separate Chinese-character, English-word, and number counts. Markdown syntax, code, image embeds, URLs, block IDs, and generated reference links are excluded from the total.
* Added a settings tool to rebuild a selected monthly archive from Daily Notes while preserving memo IDs and backing up the existing archive first.

### Improvements

* Improved card feed and mobile search navigation, including initial filtering, image card browsing, and loading states for “With images”, “With links”, and “Untagged” results. Switching filters, date ranges, or statistics periods now starts the new result range from the top, while content refreshes preserve the current scroll position and rendered batch.
* Added a responsive back action to Record Statistics. Returning now restores the source route, filters, search state, and Random Reunion results across desktop and mobile layouts.
* Improved the loading experience of Record Statistics and reduced layout shifts when opening it for the first time. The Common Tags chart now has a dedicated empty state, accessible interactions, consistent bar thickness, and capsule-shaped bars, and the earliest/latest record preview modules have been removed.
* Added caching for Memo word statistics to reduce repeated Markdown parsing.
* Improved card menu placement so the menu now opens in the direction with more available space.
* Improved localized error and issue messages across memo cards, trash actions, synchronization, repair, and settings maintenance tools.
* Added localized read-only notices to newly created monthly archive files while preserving existing and legacy notices.
* Improved text setting edits so valid changes are saved when the field loses focus or the settings page closes, instead of saving every intermediate keystroke.
* Added English default blacklist tags for Random Reunion, including `temp`, `temporary`, `draft`, and `archived`.
* Added an explicit migration flow for monthly memo filename formats. The new format must contain exactly one `YYYY-MM`; Knomo previews conflicts, creates a backup, rebuilds affected archives from Daily Notes, updates indexes, and rolls back generated files and indexes if migration fails.
* Improved monthly folder migration so only recognized Knomo archives are moved, including archives referenced by indexes and nested archive paths.
* Improved Daily Notes date detection with the current Obsidian locale, including localized month names, ordinal days, and ISO week formats, while preserving existing English and Chinese compatibility.
* Improved maintenance coordination so monthly filename and folder migrations wait for active Memo mutations, and new mutations wait until maintenance completes.
* Improved internal stability and test coverage for Memo Markdown rendering, progressive mobile loading, Random Reunion, and trash actions.

### Fixes

* Fixed concurrent Memo creation and stale prepared writes. Creates are now serialized, and a changed Daily Note or monthly archive is safely rebased before one bounded retry so identical Memos remain distinct.
* Fixed update, delete, restore, scan, and monthly archive operations potentially selecting another Memo with the same content or timestamp. Ambiguous matches now stop safely and leave both Markdown stores unchanged.
* Fixed safe mutations using a stale line and timestamp to update or delete a different Memo after blocks moved. Line and time alone are no longer accepted for writes.
* Fixed concurrent settings saves overwriting unrelated changes. Setting patches are now persisted serially from the latest committed state.
* Fixed monthly folder migration leaving pending Memo creates behind in the old archive or index folder. Pending creates now recover before files move.
* Fixed external monthly archive renames. Knomo now rebuilds the expected archive once, ignores its own migration moves, and reports conflicting archive targets without overwriting them.
* Fixed Daily Note scans misclassifying same-time sibling Memos after a block was removed or moved. Existing memo IDs are preserved, and only the missing Memo is tombstoned when the match is unambiguous.
* Fixed historical reference cards losing `sourceMemoId` and reference metadata after an index scan or rebuild, being omitted from Record Statistics reference counts and navigation results, or resolving to a nested quoted reference instead of the direct source. Knomo now restores metadata from memo ID aliases or uniquely matched Daily Note block targets, does not treat unresolved ordinary block links as Knomo references, and persists recovery once per affected period only when the scanned record is still current so newer metadata is not overwritten.
* Fixed mobile list continuation when the native keyboard inserts a bullet, numbered-list, or task marker without the required trailing space.
* Fixed layout initialization in environments where `ResizeObserver` is unavailable.
* Fixed settings state changing in memory when persistence fails.
* Fixed opening Knomo on mobile creating a replacement tab instead of reusing the existing Knomo leaf.
* Fixed mobile focus handling when dismissing a popup or closing the image picker. A dismissed popup no longer leaves the memo timestamp control focused, and composer focus returns only when the picker closes without selected files and the composer is still open.

### 新功能

* 新增 **记录统计** 页面，支持按周、月、年查看 Memo 趋势、记录时间分布、笔记总量、字数总量、引用数量、单日峰值、五个最常用标签，以及“有标签”“无标签”“有图片”等范围统计指标；支持在桌面端和移动端点击图表柱、标签或统计指标查看对应 Memos，也可以通过“所有笔记”打开完整主卡片流。
* 新增单条 Memo 字数统计，分别计算中文字数、英文单词数和数字数量；统计会排除 Markdown 语法、代码、图片嵌入、URL、block ID 和自动生成的引用链接。
* 设置页新增“重建指定月份归档”工具，可从 Daily Notes 重新生成月度归档，保留 memo ID，并在重建前备份现有归档。

### 改进

* 改进卡片流和移动端搜索导航，包括首次筛选、图片卡片浏览，以及“有图片 / 有链接 / 无标签”结果的加载状态。切换筛选、日期范围或统计周期时，新结果会从顶部开始；内容刷新时则保留当前滚动位置和已渲染批次。
* 为“记录统计”新增响应式返回操作；在桌面端和移动端返回时，会恢复来源页面、筛选条件、搜索状态和“随机回顾”结果。
* 改进“记录统计”的加载体验，减少首次打开时的布局偏移；“常用标签”图表新增独立空状态和无障碍交互，统一柱条粗细并改为胶囊形，同时移除最早和最晚记录预览模块。
* 为 Memo 字数统计新增缓存，减少重复解析 Markdown。
* 改进卡片菜单定位逻辑，菜单会根据可用空间自动选择更合适的展开方向。
* 改进 Memo 卡片、废纸篓操作、同步、修复和设置维护工具中的本地化错误与问题提示。
* 新创建的月度归档文件会写入对应语言的只读提示，同时保留已有提示和旧版提示。
* 改进文本设置项的编辑体验：有效修改会在输入框失焦或关闭设置页时保存，不再保存每个输入过程中的中间值。
* 为“随机回顾”新增英文默认排除标签，包括 `temp`、`temporary`、`draft` 和 `archived`。
* 新增月度 Memos 文件名格式的显式迁移流程。新格式必须恰好包含一个 `YYYY-MM`；Knomo 会预检冲突、创建备份、从日记重建受影响的月度归档并更新索引，迁移失败时回滚生成文件和索引。
* 改进月度文件夹迁移，只移动 Knomo 可识别的归档文件，包括索引引用的归档和嵌套归档路径。
* 改进日记日期识别，支持 Obsidian 当前语言环境中的本地化月份名称、序数日期和 ISO 周格式，同时保留现有中英文格式兼容性。
* 改进维护任务协调：月度文件名和文件夹迁移会等待正在进行的 Memo 操作，新的 Memo 操作也会等待维护任务结束。
* 改进 Memo Markdown 渲染、移动端渐进加载、随机回顾和废纸篓操作的内部稳定性与测试覆盖。

### 修复

* 修复并发创建 Memo 和预备写入过期的问题。创建操作现在会串行执行；日记或月度归档发生变化时，会安全重算写入内容并进行一次有限重试，确保内容相同的 Memo 仍保持独立。
* 修复更新、删除、恢复、扫描和月度归档操作可能误选内容或时间相同的其他 Memo 的问题。匹配存在歧义时会安全停止，并保持日记和月度归档不变。
* 修复 block 移动后，安全写操作仍可能依据过期行号和相同时间误改或误删其他 Memo 的问题；写操作不再仅凭行号和时间执行。
* 修复并发保存设置时，不相关修改可能互相覆盖的问题；设置 patch 现在会基于最近一次成功状态串行持久化。
* 修复月度文件夹迁移后，pending Memo 创建可能继续写入旧归档或旧索引目录的问题；迁移前会先完成 pending create 恢复。
* 修复外部重命名月度归档后的恢复逻辑。Knomo 现在只重建一次预期归档，会忽略自身迁移产生的移动事件，并在目标冲突时提示而不覆盖文件。
* 修复删除或移动 block 后，日记扫描可能误判同一时间创建的相邻 Memo 的问题。现在会保留已有 memo ID，并仅在匹配明确时将缺失 Memo 标记为已删除。
* 修复历史引用卡片在索引扫描或重建后丢失 `sourceMemoId` 和引用元数据、未计入记录统计引用数量和查看结果，以及多层引用恢复时选错来源的问题。Knomo 现在会通过 memo ID 别名或唯一匹配的日记 block 目标恢复元数据，优先识别当前直接来源，不把无法确认的普通块链接误判为 Knomo 引用；恢复结果按受影响月份持久化一次，并且只在扫描记录仍为当前版本时写入，避免覆盖较新的元数据。
* 修复移动端原生键盘插入缺少尾随空格的无序列表、有序列表或任务列表标记时，列表无法正确续写的问题。
* 修复运行环境不支持 `ResizeObserver` 时界面布局无法初始化的问题。
* 修复设置保存失败时，内存中的设置状态仍被修改的问题。
* 修复移动端打开 Knomo 时可能新建替代标签页、而不是复用现有 Knomo 页面的问题。
* 修复移动端关闭弹层或图片选择器时的焦点处理：关闭弹层不再让 Memo 时间控件保持聚焦；仅在图片选择器未返回文件且编辑器仍打开时恢复编辑器焦点。
