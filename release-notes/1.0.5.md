## Knomo 1.0.5

### Improvements

* Added a unified `npm run verify` workflow and documented the core verification steps in the README, including typecheck, tests, build, i18n checks, whitespace checks, and Obsidian compatibility scans.
* Added a mobile QA checklist for manually validating mobile composer, keyboard, navigation, image picker, and lifecycle behavior.
* Split more Knomo view logic into focused modules for composer draft handling, save shortcuts, list enter behavior, mobile toolbar guards, native image picking, card image rendering, markdown link parsing, task checkbox changes, search debounce, date watching, sidebar state, title labels, record-stat drilldowns, and image preview scroll locking.
* Improved mobile and narrow-screen UI resilience by moving runtime layout updates through Obsidian CSS variable helpers and making maintenance settings wrap more cleanly.
* Improved list filter and title state handling so desktop titles can reflect transient search, date, and record-stat filters while mobile titles stay anchored to the active list context.

### Fixes

* Fixed the mobile image insertion flow. Tapping the image button no longer forces the composer to blur, does not treat early system focus changes as picker cancellation, and keeps the native picker input alive until the selected files are returned.
* Fixed mobile composer focus restoration after image insertion. If the composer was focused before opening the image picker, focus is restored after the image links are inserted; if the keyboard was already dismissed, Knomo no longer forces it open.
* Fixed selected image files not being inserted after returning from the mobile photo library or camera.
* Fixed deleted memo restore and purge actions so they target the memo's original month instead of relying on broad lookup behavior.
* Fixed memo-index loading to reject malformed JSON and invalid memo records with clearer period, memo id, and field-level errors.
* Fixed mobile compact-navbar cleanup so injected chrome is removed and temporary CSS variables are reset when the mobile leaf lifecycle changes.

### 改进

* 新增统一的 `npm run verify` 验证流程，并在 README 中补充核心验证步骤，包括类型检查、测试、构建、i18n 检查、空白字符检查和 Obsidian 兼容性扫描。
* 新增移动端 QA checklist，用于手动验证移动端输入框、键盘、导航、图片选择器和生命周期行为。
* 继续拆分 Knomo view 内部逻辑，将输入草稿、保存快捷键、列表回车行为、移动端工具栏保护、原生图片选择、卡片图片渲染、Markdown 链接解析、任务复选框变更、搜索防抖、日期监听、侧边栏状态、标题文案、记录统计下钻和图片预览滚动锁定拆成更聚焦的模块。
* 改进移动端和窄屏 UI 稳定性，运行时布局更新改用 Obsidian CSS 变量 helper，并让维护类设置项在窄屏下更自然换行。
* 改进列表筛选和标题状态处理：桌面端标题可以反映搜索、日期、记录统计等临时筛选状态，移动端标题则保持跟随当前列表上下文。

### 修复

* 修复移动端插入图片流程：点击图片按钮不再强制让输入框失焦，不再把系统提前返回的 focus 误判为取消选择，并且会一直保留原生图片选择 input，直到系统返回已选文件。
* 修复移动端插入图片后的输入框焦点恢复：如果打开图片选择器前输入框已获焦，插入图片链接后会恢复焦点；如果键盘原本已收起，则不会强制弹起键盘。
* 修复从手机图片库或相机返回后，已选择图片没有插入输入框的问题。
* 修复已删除 memo 的恢复和彻底删除定位逻辑，现在会按 memo 原始月份精确处理，避免依赖宽泛查找。
* 修复 memo-index 加载校验，现在会对损坏 JSON 和非法 memo 记录给出更明确的 period、memoId 和字段级错误。
* 修复移动端 compact navbar 生命周期清理，移动端 leaf 变化时会移除注入的 chrome 并重置临时 CSS 变量。
