## Knomo 1.1.0

### Improvements

* Added “Shuffle Day,” which picks a date from historical records and displays that day’s memos in chronological order.
* Improved interaction feedback for the refresh button and enhanced refresh stability and performance.
* Added a unified `npm run verify` validation workflow, and improved the internal logic and feature module code of the Knomo view for easier maintenance.

### Fixes

* Fixed issues found when inserting images on mobile.
* Fixed the positioning logic for restoring and permanently deleting deleted memos, avoiding reliance on broad matching.
* Fixed memo-index loading validation.
* Fixed lifecycle cleanup for the compact navbar on mobile.

---

### 改进

* 新增「往日漫游」，从历史记录中抽取一个日期，并按时间顺序展示当天的 Memos。
* 改进刷新按钮的操作反馈交互，改善刷新稳定性能。
* 新增统一的 `npm run verify` 验证流程，改进 Knomo view 内部逻辑和功能模块代码，便于维护。

### 修复

* 修复移动端插入图片时发现的问题。
* 修复已删除 memo 的恢复和彻底删除定位逻辑，避免依赖宽泛查找。
* 修复 memo-index 加载校验。
* 修复移动端 compact navbar 生命周期清理。
