## Knomo 1.1.3

### Improvements

* Improved memo image loading with shared resource caching, coordinated load queues, and preview reuse so image-heavy card feeds and previews stay more responsive.
* Improved mobile image loading so card images can release queue slots earlier while decoded image resources are still cached safely.
* Improved mobile drawer and search overlay positioning so they follow the actual Obsidian mobile header instead of relying only on default safe-area offsets.

### Fixes

* Fixed image preview cache invalidation and reuse edge cases that could leave stale preview resources behind after image changes.
* Fixed mobile search overlay spacing and close-button sizing to better match the measured header area.

---

### 改进

* 改进 Memo 图片加载，加入共享资源缓存、协调加载队列和预览复用，让图片较多的卡片流和预览保持更顺畅。
* 改进移动端图片加载，卡片图片可以更早释放加载队列位置，同时仍安全缓存已解码的图片资源。
* 改进移动端抽屉和搜索浮层定位，使其跟随 Obsidian 移动端实际标题栏位置，而不是只依赖默认安全区偏移。

### 修复

* 修复图片预览缓存失效与复用相关的边界问题，避免图片变更后残留过期预览资源。
* 修复移动端搜索浮层间距和关闭按钮尺寸，使其更贴合测量到的标题栏区域。
