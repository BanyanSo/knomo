## Knomo 1.1.7

### Improvements

* Improved Repair Knomo data so it can recover from memo-index sync-conflict copies, preserve memo IDs from recoverable index data, and report how many duplicate index records were cleaned.
* Improved memo-index reading consistency across All notes, issue lists, record statistics, current-month queries, and monthly archive rebuilds so duplicate index records are filtered consistently.
* Improved memo-index file watching so deleting or moving the canonical monthly index triggers a bounded recent daily-note recovery scan.

### Fixes

* Fixed sidebar drawer layering so card more menus, the All notes menu, and desktop search popovers can stay open while the sidebar drawer opens above them on desktop and mobile.
* Fixed duplicate memo cards and duplicate statistics caused by multiple index records pointing to the same daily-note block.
* Fixed Repair Knomo data so it can continue rebuilding from daily notes when a canonical memo-index file is unreadable.
* Fixed false-positive monthly archive conflict warnings when a folder path or unrelated Markdown filename contains conflict-like words.
* Fixed scoped 30-day and 90-day repairs so recoverable memo IDs are restored even when the daily-note content has not changed.
* Fixed Repair Knomo data cleanup so it only removes memo-index conflict copies after a successful repair and leaves monthly Markdown conflict copies untouched for manual review.

---

### 改进

* 改进“修复 Knomo 数据”，现在可从 memo-index 同步冲突副本恢复 memoId，并显示已清理的重复 index 记录数量。
* 统一 All notes、问题列表、记录统计、当前月查询和月度归档重建的 memo-index 读取逻辑，避免重复 index 记录在部分入口继续泄漏。
* 改进 memo-index 文件监听：当 canonical 月度 index 被删除或移走时，会触发一次有界的最近日记恢复扫描。

### 修复

* 修复侧边栏抽屉层级与弹框交互：桌面端和手机端打开侧边栏时，卡片更多菜单、全部笔记菜单和桌面搜索弹框可保持打开，并由侧边栏抽屉置顶覆盖。
* 修复多个 index 记录指向同一日记 block 时，可能出现重复 memo 卡片和重复统计的问题。
* 修复 canonical memo-index 文件不可读时，“修复 Knomo 数据”仍可继续从日记重建的问题。
* 修复文件夹路径或无关 Markdown 文件名包含类似 conflict 字样时，月度归档冲突提示可能误报的问题。
* 修复 30 天/90 天范围修复中，日记正文未变化时 recoverable memoId 可能没有写回 canonical index 的问题。
* 修复“修复 Knomo 数据”的清理行为：成功修复后只清理 memo-index 冲突副本，不自动删除或改写月度 Markdown 冲突副本。
