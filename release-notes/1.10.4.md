## Knomo 1.10.4

Knomo 1.10.4 is a **stability and bug-fix release following the major 1.10 update**.

This release fixes issues found after 1.10.0 and further improves Daily Note creation, historical loading, image browsing, and mobile interactions.

### Fixes & Improvements

#### Daily Note templates

- When today's Daily Note does not exist, Knomo now uses the configured Obsidian Daily Notes template before appending the Memo.

- Date, time, and title template variables are resolved correctly.

- Existing Daily Notes are not templated again.

- If the configured template cannot be read, Knomo no longer silently creates an empty Daily Note.

#### Historical loading

- Improved **Load more** behavior across desktop and mobile.

- When there are no older Memos available, the button is removed immediately instead of remaining visible because the current Memo list did not change.

- Real historical pagination continues to work normally when older Memos are available.

#### Image loading

- Improved visible-first image loading and scheduling while browsing Memo cards.

- Image placeholders now remain until decoding is complete, reducing premature transitions and visual flicker.

- Recently loaded images can be reused when switching filters or returning to the card flow or mobile search, reducing unnecessary reloads.

- Cached images are invalidated when their source changes or the view is closed.

#### Mobile interactions

- **Tag suggestions**: Fixed a conflict between touch selection and input blur. Selecting a tag now keeps the cursor and keyboard active, while scrolling the suggestion list no longer causes accidental selection.

- **Pinned Time Buoy**: Fixed flickering during asynchronous queries. The Memo list and pinned buoy now update from the same query result, and stale requests can no longer overwrite the latest state.

---

### Recent highlights from Knomo 1.10

If you are upgrading from an earlier version, the 1.10 series introduced several major improvements:

- **Recent 3-day time flow** groups Memos from today, yesterday, and the day before for faster review of recent notes.

- **Customizable Composer toolbar** lets you show, hide, and reorder actions, with additional Markdown tools including bold, highlight, links, and numbered lists.

- **New local Catalog architecture** keeps Daily Notes as the primary source for active Memos while using a rebuildable local Catalog for browsing, search, filtering, statistics, tags, Shuffle Day, Time Buoy, and historical queries.

- **Better multi-device behavior** keeps the Catalog local to each device and rebuilds it from synced Daily Notes instead of syncing the local index itself.

- **Incremental updates** process changed Daily Notes instead of repeatedly performing unnecessary full scans.

- Existing `- HH:mm` and `- HH:mm:ss` Memo entries in Daily Notes are recognized automatically without a separate manual import.

Knomo 1.10.4 是 **1.10 大版本发布后的稳定性与问题修复版本**。

本次更新主要修复 1.10.0 发布后发现的问题，并进一步改善日记创建、历史加载、图片浏览和移动端交互体验。

### 修复与改进

#### 日记模板

- 当当天日记不存在时，Knomo 会先使用 Obsidian 配置的日记模板，再追加 Memo。

- 正确处理模板中的日期、时间和标题变量。

- 已存在的 Daily Note 不会重复套用模板。

- 如果模板读取失败，不再静默创建空白日记。

#### 历史加载

- 优化桌面端与移动端的「加载更多」逻辑。

- 已无更早 Memo 时，会立即移除「加载更多」按钮，不再因为当前 Memo 列表内容未发生变化而残留。

- 确实存在更早历史记录时，分页加载继续正常工作。

#### 图片加载

- 优化卡片浏览时的图片可见优先加载与调度。

- 图片完成解码后再撤除占位状态，减少提前切换和视觉闪烁。

- 切换筛选、返回卡片流或移动搜索时，可复用近期已经加载的图片，减少重复加载。

- 图片资源发生变化或关闭视图后，相关缓存会自动失效并清理。

#### 移动端交互

- **标签候选框**：修复触摸选择与输入框失焦之间的冲突。点选标签后保持光标和键盘，滑动候选列表时不会误选。

- **置顶时光浮标**：修复异步查询过程中的闪动。Memo 列表与置顶浮标现在基于同一次查询结果更新，旧请求不会覆盖最新状态。

### Knomo 1.10 近期主要更新

如果你从较早版本升级，1.10 系列近期还带来了以下主要变化：

- **近三天时间流**：将今天、昨天和前天的 Memo 按日期分组，更方便快速浏览近期记录。

- **可自定义输入工具栏**：支持显示、隐藏和调整按钮顺序，并增加加粗、高亮、链接和有序列表等常用 Markdown 操作。

- **新的本地 Catalog 架构**：Daily Notes 继续作为活动 Memo 的主要来源，可重建的本地 Catalog 负责浏览、搜索、筛选、统计、标签、往日漫游、时光浮标和历史查询。

- **更适合多设备使用**：Catalog 仅保存在当前设备，各设备根据同步后的 Daily Notes 建立自己的本地数据，不再同步本地索引本身。

- **增量更新**：只处理发生变化的 Daily Notes，减少重复读取和不必要的全量扫描。

- 日记中已有的 `- HH:mm` 和 `- HH:mm:ss` Memo 可以自动识别，无需单独执行手动导入。
