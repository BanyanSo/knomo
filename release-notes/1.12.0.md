## Knomo 1.12.0

Knomo 1.12.0 introduces **Things**, a dedicated view for Memos with checkboxes, adds quick commands and a more responsive desktop layout, and improves Composer drafts, saving, and Markdown editing.

### Highlights

#### Things

- Browse Memos containing supported Markdown checkboxes in one place, including completed and incomplete items.
- Combine Things with tag, text, and date filters to find the Memos you need.
- Mobile search keeps the Things filter active while searching.

#### Quick commands

- Open **New memo**, **Random revisit**, **Shuffle day**, **Time buoy**, **Record statistics**, and **On this day** from Obsidian’s command palette, or assign your own hotkeys.
- Reuse an existing Knomo view when available, or open one before running the command.
- Start a new Memo without losing the current Composer draft; Time buoy requires the feature to be enabled.

#### Responsive desktop layout

- Adapt to the current Knomo pane: use a persistent Sidebar at widths of 780px and above, and a compact header with a Sidebar drawer below 780px.
- Keep the drawer within its pane, including very narrow splits, with a visible close button, Escape support, and keyboard focus handling.
- Preserve Sidebar width and collapse preferences, drafts, and search state when resizing between layouts.
- Improve toolbar wrapping and content sizing in narrow panes while keeping the existing Mobile layout.

#### Composer drafts and saving

- Temporarily keep your new Memo draft when editing an existing Memo, then restore its text, reference, selection, and scroll position after saving or canceling the edit.
- Keep the current draft when closing and reopening the Composer within the same view.
- Show a dedicated **Save** action when editing, and prevent repeated submissions or content changes while saving.
- Keep edits when saving fails or the original Memo has changed, so you can resolve the issue without losing your work.
- Prevent delayed image or reference operations from inserting content into a different editing session.

#### Markdown editing and checkboxes

- Improve Markdown display and source reveal for lists, formatting, links, and code boundaries. Editing a marker or moving the selection into formatted text reveals the relevant source.
- Improve cursor movement, selection, paste, undo, and input-method interactions around Markdown formatting.
- Toggle supported checkboxes directly in the Composer draft, with undo and redo support.
- Align checkbox recognition across the Composer, Memo cards, and Daily Notes, including nested lists and blockquotes, while excluding code examples.
- Improve Memo card Markdown rendering consistency with Obsidian and refuse checkbox changes when the task position cannot be safely confirmed.

Knomo 1.12.0 新增 **「勾事记」**，集中浏览包含勾选项的 Memo，增加快捷命令与桌面端响应式布局改进，并优化 Composer 草稿、保存流程与 Markdown 编辑体验。

### 主要更新

#### 勾事记

- 集中查看包含受支持 Markdown 勾选项的 Memo，涵盖已完成与未完成项目。
- 支持结合标签、文本搜索和日期筛选，查找需要的 Memo。
- 移动端搜索时继续保留「勾事记」筛选范围。

#### 快捷命令

- 支持从 Obsidian 命令面板执行「新建 Memo」「随机重逢」「往日漫游」「时光浮标」「记录统计」「那年今日」，也可自行绑定快捷键。
- 优先复用已打开的 Knomo 视图；没有视图时自动打开后执行命令。
- 新建 Memo 时保留当前 Composer 草稿；「时光浮标」命令需先启用对应功能。

#### 桌面端响应式布局

- 根据当前 Knomo 分栏宽度适配布局：780px 及以上使用常驻侧边栏，低于 780px 使用紧凑标题栏与侧边栏抽屉。
- 抽屉限制在所属分栏内，支持极窄分栏，并提供可见关闭按钮、Escape 关闭与键盘焦点管理。
- 调整分栏宽度、切换布局时保留侧边栏宽度和折叠偏好、草稿及搜索状态。
- 改善窄分栏中的工具栏换行与内容宽度适配，保留现有移动端布局。

#### Composer 草稿与保存

- 编辑已有 Memo 时暂存新建草稿，保存或取消编辑后恢复草稿正文、引用、选区和滚动位置。
- 在同一视图内关闭并重新打开 Composer 时保留当前草稿。
- 编辑时显示独立的「保存」操作；保存期间阻止重复提交与内容修改。
- 保存失败或原 Memo 已发生变化时保留编辑内容，便于处理问题后继续操作。
- 防止延迟完成的图片或引用操作将内容插入另一段编辑会话。

#### Markdown 编辑与勾选项

- 改进列表、格式、链接和代码边界的 Markdown 显示与源码展开；编辑标记或将选区移入格式文本时，显示相关源码。
- 改善 Markdown 格式附近的光标移动、选区、粘贴、撤销和输入法交互。
- 支持直接在 Composer 草稿中切换勾选项，并通过撤销、重做恢复状态。
- 统一 Composer、Memo 卡片和 Daily Notes 的勾选项识别，涵盖嵌套列表与引用块，并排除代码示例。
- 改善 Memo 卡片与 Obsidian 的 Markdown 渲染一致性；无法安全确认勾选项位置时拒绝修改。
