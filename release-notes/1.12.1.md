## Knomo 1.12.1

### Native Obsidian URL shortcuts

- Open Knomo from iOS Shortcuts or other apps with `obsidian://knomo?vault=<vault-id>&command=open-view`.
- Run the existing six Quick Commands through the same URL entry: `new-memo`, `random-revisit`, `shuffle-day`, `time-buoy`, `record-stats`, and `on-this-day`.
- Use Obsidian's native vault routing with a Vault ID or name. Prefer a device-local Vault ID; omitting `vault` uses the vault selected by Obsidian.
- Reuse existing Knomo views and Quick Command behavior, including initialization waits, cancellation, and the Time buoy enable check. Missing or invalid commands do nothing; URLs cannot insert Memo content or save it automatically.

See [URL usage and multi-vault instructions](../README.md#obsidian-url-shortcuts).

### 原生 Obsidian URL 快捷指令

- 支持通过 `obsidian://knomo?vault=<vault-id>&command=open-view` 从 iOS「快捷指令」或其他应用打开 Knomo。
- 支持通过同一 URL 入口执行现有六个快捷命令：`new-memo`（新建 Memo）、`random-revisit`（随机重逢）、`shuffle-day`（往日漫游）、`time-buoy`（时光浮标）、`record-stats`（记录统计）和 `on-this-day`（那年今日）。
- 复用 Obsidian 原生 Vault 路由，支持 Vault ID 或名称。推荐使用设备本地 Vault ID；省略 `vault` 时使用 Obsidian 实际选中的 Vault。
- 复用已有 Knomo 视图与快捷命令行为，保留初始化等待、取消及「时光浮标」开关检查。缺失或非法命令不执行功能；URL 不支持插入 Memo 正文或自动保存。

参见 [URL 用法与多 Vault 使用说明](../README.zh-CN.md#obsidian-url-快捷指令)。
