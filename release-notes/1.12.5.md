## Knomo 1.12.5

### New features
- Native Obsidian URL shortcuts: Open Knomo from iOS Shortcuts or other apps with `obsidian://knomo?vault=<vault-id>&command=open-view`, or run any of the six Quick Commands: `new-memo`, `random-revisit`, `shuffle-day`, `time-buoy`, `record-stats`, and `on-this-day`. Supports Obsidian's native vault routing by Vault ID or name; URLs do not insert or automatically save Memo content. See [URL usage and multi-vault instructions](../README.md#obsidian-url-shortcuts).
- Image retry: Tap to retry recoverable image loading failures.

### Improvements
- Image performance: Prioritize visible images and spread card rendering across frames to reduce loading and scrolling stalls in image-heavy lists.
- Mobile filter lists: Reuse loaded image cards and preserve the scroll position when returning to a filter. Load more results without rebuilding the existing list.
- Mobile Tag suggestions: Enlarge touch targets and allow long tags to wrap for easier selection.
- Settings navigation: Group settings into Record, Archive & Data, and About tabs, while preserving unfinished text input when switching tabs or refreshing the panel.

### Fixes
- Improve recovery from interrupted image loading to prevent temporary interruptions from leaving images stuck in a failed state.
- Fix accidental tag selection while scrolling or when the editing context changes, and prevent taps from passing through to the editor after the suggestion popup closes.

### 新增功能
- 原生 Obsidian URL 快捷指令：支持通过 `obsidian://knomo?vault=<vault-id>&command=open-view` 从 iOS「快捷指令」或其他应用打开 Knomo，也可执行现有六个快捷命令：`new-memo`（新建 Memo）、`random-revisit`（随机重逢）、`shuffle-day`（往日漫游）、`time-buoy`（时光浮标）、`record-stats`（记录统计）和 `on-this-day`（那年今日）。支持 Obsidian 原生 Vault ID 或名称路由；URL 不支持插入 Memo 正文或自动保存。参见 [URL 用法与多 Vault 使用说明](../README.zh-CN.md#obsidian-url-快捷指令)。
- 图片重试：可恢复的图片加载失败支持点击重试。

### 改进
- 图片性能：优先加载可见图片，并将卡片渲染分散到多帧处理，减少多图片列表加载和滚动时的卡顿。
- 移动端筛选列表：返回筛选列表时复用已加载的图片卡片、保留滚动位置；加载更多结果时增量追加，避免重建已有列表。
- 移动端 Tag 候选：扩大标签候选项的触控区域，支持长标签换行，方便点选。
- 设置导航：将设置分为「记录」「归档与数据」「关于」三个页签，切换页签或刷新面板时保留尚未完成的文本输入。

### 修复
- 改进图片加载中断后的恢复，避免临时中断导致图片持续处于失败状态。
- 修复滑动候选列表或编辑上下文变化时的标签误选，并防止候选弹层关闭后的点击穿透到编辑器。
