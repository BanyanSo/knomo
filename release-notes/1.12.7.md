## Knomo 1.12.7

### New features
- Local draft recovery: Restore unfinished new and edited Memos after reopening Knomo or restarting Obsidian, including references, selection, scroll position, and completed image attachments. Drafts stay on the current device and are isolated by vault.

### Improvements
- Startup: Run independent initialization work in parallel and avoid duplicate Daily reads to reduce startup overhead.
- Statistics and tags: Reuse shared aggregation results to reduce repeated index reads when updating counts and tag lists.
- Tag suggestions: Process tag indexing in batches that yield to other work, and publish complete results together to keep the interface responsive and avoid partial tag lists. Reuse unchanged suggestion results and batch popup measurements to reduce repeated filtering and layout work.
- Mobile tag suggestions: Prepare the tag index during idle time after the first screen is rendered, and pause indexing while the keyboard opens or input-method composition is active to reduce contention with typing.
- Composer toolbar: Keep tools and send actions on one row on desktop and mobile, with horizontal scrolling for overflowing tools and mouse dragging on desktop.
- Time Buoy: Load results page by page and refresh invalidated pages when the index changes, preventing outdated results from appearing after switching tabs or refreshing.
- Reference queries: Reuse reads of the same target file within each query to reduce repeated work while keeping later queries up to date.
- Settings layout: Improve control alignment and wrapping in narrow desktop views and on mobile, keeping toggles and action buttons from overlapping.

### Fixes
- Load tag suggestions reliably on first use while typing continues, and prevent late results from reopening dismissed suggestions or appearing in a different Composer session.
- Render current sidebar tags when the sidebar opens and update them when loading completes, preserving active tag filters and expanded groups.
- Preserve scroll position and focus when saving toolbar visibility, order, or reset settings, avoiding jumps in mobile settings.
- Prevent older Composer sessions from overwriting or clearing newer local drafts after a session is replaced or the plugin is unloaded.
- Allow index recovery after an initial scan failure, and keep index and view refreshes working when Monthly initialization fails.
- Make full-width character and whitespace matching consistent across search results, counts, and mobile filtering.
- Prevent stale Monthly projection tasks from committing outdated results after the source changes.
- Wait for historical Daily coverage before treating today's Time Buoy results as complete, so reminders from older notes are included.
- Reject Daily writes when the selected file has been moved or replaced. Keep recovered edit text when its original target is no longer valid, and ask users to check Daily before retrying an unconfirmed save.

### 新增功能
- 本地草稿恢复：重新打开 Knomo 或重启 Obsidian 后，可恢复未完成的新建和编辑草稿，包括引用、选区、滚动位置及已完成的图片附件。草稿保存在当前设备，并按 Vault 隔离。

### 改进
- 启动：并行执行独立初始化任务，避免重复读取 Daily，减少启动开销。
- 统计与标签：复用共享聚合结果，减少更新计数和标签列表时的重复索引读取。
- 标签建议：分批构建标签索引并让出执行时间，完整结果就绪后统一更新，减少界面阻塞和不完整标签列表的显示。复用未变化的候选结果并批量测量弹窗，减少重复筛选和布局计算。
- 移动端标签建议：首屏显示后利用空闲时间预热标签索引，在键盘弹出和输入法组合输入期间暂停索引构建，减少与输入操作争用执行时间。
- 编辑器工具栏：桌面和移动端的工具与发送操作保持单行排列，工具超出宽度时可横向滚动，桌面端支持鼠标拖动。
- 时光浮标：按页加载结果，索引变化后重新加载失效页面，避免切换页签或刷新后显示过期结果。
- 引用查询：在单次查询内复用同一目标文件的读取，减少重复处理，同时确保后续查询读取最新内容。
- 设置布局：改善桌面窄视图和移动端的控件对齐与换行，避免开关和操作按钮重叠。

### 修复
- 修复首次使用标签建议时继续输入导致候选未显示的问题，防止延迟返回的结果重新打开已关闭的建议或出现在另一编辑会话中。
- 打开侧栏时立即显示当前标签，并在加载完成后更新，保留已选标签筛选和分组展开状态。
- 保存工具栏显示、排序或重置设置时保留滚动位置与焦点，避免移动端设置页面跳动。
- 防止旧 Composer 会话在被替换或插件卸载后覆盖、清除较新的本地草稿。
- 初次扫描失败后可重新恢复索引；Monthly 初始化失败时，索引和视图仍可继续刷新。
- 统一搜索结果、计数和移动端筛选对全角字符及空白的匹配行为。
- 防止源内容变化后，过期的 Monthly 投影任务继续提交旧结果。
- 今日浮标等待历史 Daily 扫描覆盖完整后再视为完整结果，避免遗漏来自旧笔记的提醒。
- 当选中的 Daily 文件被移动或替换时拒绝写入；恢复的编辑草稿在原目标失效时保留文字，保存结果未确认时提示先核对 Daily 再重试。
