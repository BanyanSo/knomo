## Knomo 1.13.0

### New features

- Date search: Enter a year (`2026`), month (`2026-10`), day (`2026-10-09`), or recurring month/day (`10-09`) directly in desktop or mobile search, and combine it with text. Use `~` or `至` for ranges, including recurring ranges across year boundaries; wrap numeric dates in quotes, such as `"2026"`, to search them as text.
- Search highlights: Highlight matches in visible memo text while preserving Markdown formatting, links, task controls, and the original content used for copying.

### Improvements

- Search matching: Match continuous readable body text, tags, link targets, and image paths as separate fields, avoiding false matches across field boundaries. Body matching ignores Markdown markers, fenced code blocks, and comments.
- Date input: Keep the current results while a date is incomplete or invalid, and show a hint near the search input.
- Mobile menus: Use Obsidian menus for card actions and scope selection, highlight the current scope, and enlarge touch targets for common controls.
- Desktop menus: Add icons to scope choices, card actions, and word counts, and highlight the current scope consistently with the sidebar and mobile menus.
- Card text: Select and copy part of a memo directly from its rendered text.
- Reference previews: Preserve line breaks and whitespace, and limit long previews to four lines.
- Random reunion: Update cards in place after edits, task changes, references, or deletions while preserving the current group and card order. Sync changes across open views, including Shuffle day, Time buoy, and pinned cards. Reuse unchanged candidates and refresh only the affected Daily files after changes.
- Review views: Check the current random group when returning to the page, and reload the originally selected date in Shuffle day. Remove outdated reunion cards with a source-change notice, and keep the Shuffle action available even when the group becomes empty.
- Search and counts: Avoid reading memo bodies for unfiltered or date-only counts, and reduce unnecessary reads when combining filters.
- Time buoy: Load only the candidates needed for each page, reducing repeated scans of memos with multiple buoy dates.
- Large Daily notes: Build search data and statistics in short slices, yielding between them to reduce long uninterrupted processing.
- Trash: Reduce memory copying when updating counts and browsing pages by copying only the entries needed for display.
- Images: Limit the image-path cache and release the least recently used entries during prolonged browsing.

### Fixes

- Keep the loading state until the first memo results are confirmed on desktop and mobile, preventing a brief false empty state during initial loading or redraws.
- Prevent desktop scope and card menus from being clipped by narrow panels, window edges, or enlarged text. Keep open menus positioned during scrolling and resizing, and allow scrolling when a menu exceeds the available height.
- Restore first-tap actions after mobile cold starts, returning to the view, or closing menus, including search, new memo, sidebar, and card/scope menu controls.
- Prevent menu-closing touches from clicking through, and prevent cancelled or dragged gestures from accidentally sending a memo, clearing its reference, or cancelling an edit.
- Keep editor focus when editing or referencing a memo, or clearing its reference on mobile.
- Fix mobile Composer closing and rapid reopening, and keep confirmation dialogs above Composer.
- Keep source-reference lines and Wiki aliases visible while reference cards load or refresh, including when rendering fails.
- Fix misplaced ellipses in long Chinese reference previews on iOS.
- Fix stale Random reunion cards after saving, and prevent delayed save or refresh results from removing newer cards or reintroducing older versions in Shuffle day. Memos with identical text remain independent.

### 新增功能

- 日期搜索：桌面和移动端搜索支持直接输入年份（`2026`）、月份（`2026-10`）、日期（`2026-10-09`）或跨年月日（`10-09`），并可与文字组合搜索。使用 `~` 或 `至` 搜索日期区间，支持跨年的月日区间；给数字日期加引号（如 `"2026"`）可按普通文字搜索。
- 搜索高亮：高亮 Memo 当前可见正文中的命中文字，保留 Markdown 格式、链接、任务控件和复制时使用的原始正文。

### 改进

- 搜索匹配：可读正文按连续文字匹配，标签、链接目标和图片路径分别匹配，避免跨字段拼接产生误命中；正文匹配忽略 Markdown 标记、代码块和注释。
- 日期输入：日期尚未输入完整或不合法时，保留当前搜索结果，并在输入框附近显示提示。
- 移动端菜单：卡片操作和范围选择使用 Obsidian 菜单，突出显示当前范围，并扩大常用控件的触控区域。
- 桌面端菜单：范围选项、卡片操作和字数信息增加图标，当前范围的高亮样式与侧栏及移动端保持一致。
- 卡片正文：支持直接选择并复制 Memo 渲染正文中的部分文字。
- 引用预览：保留换行与空白，长引用最多展示四行。
- 随机重逢：编辑保存、任务勾选、引用和删除后原位同步卡片，保留当前组与卡片顺序；同步更新已打开的往日漫游、浮标和置顶卡片。复用未变化的候选，日记变化后仅更新受影响文件的候选。
- 回看页面：返回随机重逢时校验当前组，返回往日漫游时重载原选中日期；移除过期重逢卡片并提示来源变化，组内为空时仍保留“换一组”入口。
- 搜索与计数：无筛选或仅按日期计数时无需读取 Memo 正文，组合筛选时减少不必要的正文读取。
- 浮标：按页读取所需候选，减少同一条 Memo 含多个浮标日期时的重复扫描。
- 大日记索引：分片准备搜索数据和统计，期间让出执行时间，减少长时间连续处理。
- 回收站：更新数量和分页浏览时仅复制展示所需条目，减少大量快照的内存复制开销。
- 图片：限制图片路径缓存容量，连续浏览时淘汰最久未使用的缓存项。

### 修复

- 修复桌面和移动端首次加载及期间重绘时短暂显示“暂无内容”的问题，首次 Memo 结果确认前持续显示加载状态。
- 修复桌面端范围和卡片菜单在窄面板、窗口边缘或放大字体时被裁切的问题；滚动和调整尺寸时同步更新已打开菜单的位置，高度不足时支持菜单内滚动。
- 修复移动端冷启动、返回主视图或关闭菜单后首次轻触无响应的问题，覆盖搜索、新建 Memo、侧栏和卡片／范围菜单入口。
- 防止菜单关闭手势穿透到底层控件，避免取消或拖动手势误触发发送、清除引用和取消编辑。
- 修复移动端编辑、引用 Memo 或清除引用后编辑器焦点丢失的问题。
- 修复移动端 Composer 关闭与快速重新打开时的退场异常，并确保确认弹窗显示在 Composer 上方。
- 修复引用卡片加载或刷新时来源行与 Wiki 别名短暂消失的问题，渲染失败时仍保留可读来源。
- 修复 iOS 长中文引用预览中省略号位置不正确的问题。
- 修复保存后随机重逢卡片仍显示旧正文，以及迟到的保存或刷新结果移除最新卡片、在往日漫游重新追加旧版本的问题；同文 Memo 仍独立更新。
