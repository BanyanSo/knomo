## Knomo 1.13.3

### Improvements

- Typography: Keep interface labels, menus, timestamps, tags, and counts consistently sized while memo and Composer text follow Obsidian's text size. Apply consistent sizing to mobile Composer and suggestion popups.

### Fixes

- Preserve newly created Daily notes when saving fails or the write result is uncertain, protecting content written by other operations.
- Cancel pending Daily writes when the plugin is disabled or reloaded, while retaining changes already written successfully.
- Check complete block IDs, including hyphens and underscores, when restoring deleted memos to avoid false conflicts or missed collisions.
- Exclude Obsidian comments, HTML comments, and indented code from readable body searches. Preserve literal text inside inline code and boundaries around excluded content, including image descriptions, so search results, counts, and pagination agree.
- Keep Composer tools, Send, and Cancel edit controls accessible in narrow layouts and with enlarged interface text.

---

### 改进

- 字号：Memo 正文和 Composer 输入文字跟随 Obsidian 正文字号，界面标签、菜单、时间、标签与计数保持稳定字号；移动端 Composer 和候选弹窗使用一致的字号规则。

### 修复

- 新建 Memo 保存失败或写入结果不确定时保留新建的 Daily 文件，避免误删其他操作写入的内容。
- 禁用或重载插件时取消尚未提交的 Daily 写入，保留已经成功写入的正文。
- 从回收站恢复 Memo 时按完整 block ID 检查冲突，正确处理连字符和下划线，避免误判或漏判。
- 正文搜索排除 Obsidian 注释、HTML 注释和缩进代码，保留行内代码中的字面文字及被排除内容两侧的匹配边界，覆盖图片说明中的嵌套内容，使搜索结果、计数和分页保持一致。
- 修复窄布局或放大界面文字时 Composer 操作区挤占工具栏的问题，确保工具、发送和取消编辑入口可用。
