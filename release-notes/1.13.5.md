## Knomo 1.13.5

### New features

- Empty Trash: Permanently clear deleted memo recovery copies from the Trash page or command after confirmation. Prevent duplicate confirmations and operations, while leaving existing Daily notes unchanged.

### Improvements

- Mobile interface: Add a translucent frosted header that adapts to safe areas, navigation modes, themes, and reduced-transparency preferences. Unify active titles and result summaries, with wrapping in narrow layouts.
- Loading: Show lightweight skeletons only after a 250 ms wait, and retain existing cards, statistics, and sidebar tags during background updates.
- Feedback: Show page errors and retry actions inline, including statistics and sidebar tag failures. Keep settings and maintenance results visible beside their controls, with fewer duplicate notices and screen-reader announcements.
- Search: Cancel outdated loads when filters or pages change. Keep mobile search conditions, result counts, and Load more consistent across edits and repeated searches.
- References: Reduce unnecessary card rendering when unrelated files change, while keeping affected references up to date.

### Fixes

- Initial results: Open All notes on cold start and retry transient index changes. Distinguish incomplete results from an empty library, show guidance or retry actions for unavailable Daily notes, settings, or reads, and keep Monthly archive issues separate.
- Saving: Release the composer after Daily confirms a save without waiting for background indexing or refreshes. Protect newer drafts from late failures, and apply saved Time buoy settings to open views even if their query fails.
- Mobile composer: Place the caret at the draft's end when expanding it, and preserve the selection on other refocus actions.
- Pagination: Revalidate mobile search results after memo or index changes before continuing pagination. Discard outdated pages and counts, preserving unchanged cards, loaded images, and scroll position.
- Restore: Prevent duplicate restores. If content is restored but cleanup fails, retry only removing the recovery copy; if the Daily write is unconfirmed, retain the copy and prompt the user to check Daily before retrying.
- Late results: Ignore stale reference, copy, and restore results in closed or replaced views. Cancel old loading placeholders when requests end or views are hidden, and preserve the actual reason for reference or copy failures.

### 新增功能

- 清空回收站：支持从回收站页面或命令确认后永久清理已删除 Memo 的恢复副本，防止重复确认和重复执行，保留日记中已有的正文。

### 改进

- 移动界面：顶栏采用半透明磨砂背景，适配安全区、不同导航模式、明暗主题及减少透明度偏好；统一活动标题与结果摘要的字号，窄布局下支持换行。
- 加载体验：等待超过 250 毫秒再显示轻量骨架，后台更新时保留已有卡片、统计和侧栏标签。
- 操作反馈：页面错误及重试入口就地显示，覆盖统计和侧栏标签加载失败；设置与维护结果保留在对应控件附近，减少重复通知和屏幕阅读器播报。
- 搜索：筛选条件或页面变化时取消过期读取，编辑 Memo 和重复搜索后保持移动搜索条件、结果数量及“加载更多”状态一致。
- 引用刷新：无关文件变化时减少不必要的卡片重绘，同时及时更新受影响的引用。

### 修复

- 首次加载：冷启动显示全部笔记，索引短暂变化时自动重新读取；区分结果不完整与真实空库，日记、设置或读取不可用时提供指引或重试，Monthly 归档问题单独呈现。
- 保存：Daily 确认保存后即可继续使用输入框，无需等待后台索引或刷新；迟到失败不会清空新草稿，浮标设置保存后即使查询失败也应用到已打开视图。
- 移动输入框：展开草稿时将光标放在全文末尾，其他重新聚焦操作保留当前选区。
- 分页：Memo 或索引变化后，先重新确认移动搜索结果再继续分页；丢弃过期页面和计数，保留未变化的卡片、已加载图片及滚动位置。
- 恢复：防止重复恢复；正文已恢复但副本清理失败时，重试仅清理副本；Daily 写入尚未确认时保留恢复副本，提示先核对日记再重试。
- 迟到结果：已关闭或切换会话的视图忽略过期引用、复制和恢复结果；请求结束或视图隐藏时取消旧加载占位，引用和复制失败时保留实际错误原因。
