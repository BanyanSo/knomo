## Knomo 1.14.0

### New features

- **Share images:** Select “Share” from a Memo card to preview it as a PNG in one of four templates: Paper, Daybook, Reflection, and Midnight. Share, copy, or save using the options available on your device. If no option is available or an output action fails, you can save the image to the Vault root.
- **Share image content:** Common Markdown, static images, tasks, and expanded Callouts are supported. Mathematical notation, footnotes, HTML, dynamic queries or diagrams, and note, audio, video, or document embeds cannot yet be converted. Knomo explains the issue instead of generating an incomplete image.
- **Related memos:** Cards show previews of memos that reference them. Open “Relation details” to see how many memos refer to the current one and browse all direct referrers, newest first. Follow connections across multiple levels and return to the previous Memo or list with your reading position preserved. Relationships refresh as notes and links change, with retry available when loading fails.
- **Reference statistics:** “Referenced notes” counts memos dated in the selected period that are currently referenced by other memos; the referring memos may be from other dates. Open the matching memos and use search and filters. The existing metric is now called “Notes containing references” to distinguish the two counts.

### Improvements

- Organize card actions into clearer groups and show relation details when reference information is available.
- Refine mobile navigation, native controls, and keyboard focus when moving between Memo views.
- Improve Markdown presentation in cards and Daily notes, including paragraph and heading spacing and horizontal scrolling for wide tables.
- Optimize relation indexing and WikiLink suggestions to reduce repeated work.

### Fixes

- Preserve Markdown blank lines, indentation, and block reference placement when saving and editing Memos, keeping Daily parsing, Monthly projections, and Trash recovery consistent.
- Fix four-column continuation indentation and line breaks in blockquotes and Callouts; preserve the formatting of code, tables, formulas, and embeds.
- Preserve reference previews during Memo updates, and prevent outdated relation results from replacing newer information.
- Fix startup checks missing external changes to historical Monthly archives. Affected archives managed by Knomo are regenerated from Daily; files whose ownership cannot be confirmed are not overwritten.

### 新增功能

- **分享图片：** 在 Memo 卡片菜单选择“分享”，将记录预览为 PNG 图片，提供素页、日序、观照和墨夜四种模板。可根据设备支持的方式分享、复制或保存；没有可用方式或输出失败时，也可保存至 Vault 根目录。
- **图片内容：** 支持常用 Markdown、静态图片、任务列表和展开的 Callout。数学公式、脚注、HTML、动态查询或图表，以及笔记、音视频或文档嵌入暂不支持转换；Knomo 会提示原因，避免生成不完整的图片。
- **关联记录：** 卡片展示引用该 Memo 的其他记录摘要。打开“关联详情”，可查看引用者数量并按时间倒序浏览全部直接引用者。支持逐层查看关联关系，返回上一条 Memo 或列表时保留阅读位置。笔记和链接变化后会更新关系，加载失败时可重试。
- **引用统计：** “被引用的记录数”统计所选期间内、当前被其他 Memo 引用的记录；引用者可以来自其他日期。可打开对应记录并使用搜索和筛选。原指标更名为“含引用的记录数”，便于区分两种统计口径。

### 改进

- 重新分组卡片操作菜单，并在有引用信息时提供关联记录入口。
- 优化移动端导航、原生控件，以及切换 Memo 页面时的键盘焦点体验。
- 优化卡片与 Daily 中的 Markdown 排版，包括段落和标题间距，以及宽表格横向滚动。
- 优化关联关系索引和 WikiLink 候选计算，减少重复处理。

### 修复

- 保存和编辑 Memo 时保留 Markdown 空行、缩进和块引用标识位置，使 Daily 解析、月度归档投影与回收站恢复保持一致。
- 修复四列续行缩进以及引用块、Callout 正文的换行处理，保留代码、表格、公式和嵌入内容的格式。
- 保留 Memo 更新过程中的引用预览，避免过期的关联结果覆盖较新的信息。
- 修复启动核对历史月度归档时可能遗漏外部修改的问题；从 Daily 重新生成受影响且由 Knomo 管理的归档，不覆盖归属不明的文件。
