## Knomo 1.14.0

### New features

- Add related memos: cards show a cited-by count and up to two previews. Open Related memos to browse the current memo, its reference sources, and all direct referrers, newest first.
- Follow related memos across multiple levels, then return to the previous memo or original list with the reading position preserved.
- Add “Referenced memos” to record statistics. Open the matching memos for the selected period, with existing search and filters available. Rename the existing reference metric to “Memos with references” to clarify the two counts.

### Improvements

- Load long relation lists as you scroll. Refresh affected relationships when notes or links change, with loading, pending-update, and retry states.
- Refine Markdown spacing in memo cards and Daily notes, including compact paragraphs, heading spacing, and horizontal scrolling for wide tables.

### Fixes

- Preserve Markdown blank lines, indentation, and block reference placement when saving and editing memos, keeping Daily parsing, Monthly projections, and Trash recovery consistent.
- Fix four-column continuation indentation changing the interpretation of Markdown content.
- Fix line-break handling in blockquotes and Callout bodies while preserving the formatting of code, tables, formulas, and embeds.

### 新增功能

- 新增关联记录：卡片显示被引用数量与最多两条预览，可打开关联记录页面，浏览当前 Memo、引用来源，以及按时间倒序排列的全部直接引用者。
- 支持逐层浏览关联记录，返回上一条记录或原列表时保留阅读位置。
- 记录统计新增“被引用的记录数”，可查看所选期间对应的 Memos，并使用现有搜索与筛选；原引用指标更名为“含引用的记录数”，明确区分两种统计口径。

### 改进

- 关联记录长列表随滚动加载；笔记或链接变化时更新受影响的关系，并提供加载、待更新和失败重试状态。
- 优化卡片与 Daily 中的 Markdown 排版，包括紧凑段落、标题间距和宽表格横向滚动。

### 修复

- 保存与编辑 Memo 时保留 Markdown 空行、缩进和块引用标识位置，使 Daily 解析、月度归档投影与回收站恢复保持一致。
- 修复四列续行缩进改变 Markdown 内容解析语义的问题。
- 修复引用块与 Callout 正文的换行处理，保留代码、表格、公式和嵌入内容的原有格式。
