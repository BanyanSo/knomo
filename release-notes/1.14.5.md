## Knomo 1.14.5

### New features

- **Referenced filter:** Browse Memos that are referenced by other Memos, and combine the filter with search and date options on desktop and mobile.

### Improvements

- **Common tags:** Weekly, monthly, and yearly statistics now show up to 10 tags. Each Memo is counted once per directly applied full tag, so `#project` and `#project/a` are counted separately. Selecting a tag shows Memos directly marked with it; the sidebar tag filter continues to include child tags.
- Improve the mobile Composer's opening, keyboard positioning, and close-and-reopen transitions while keeping drafts when closed.
- Keep loaded card images more stable during refreshes and filter changes, and preserve reading position when mobile search results refresh or expand. Refresh affected previews when local attachments change.
- Reduce unnecessary work in hidden views and when cards are removed. Prepare record statistics in stages, so basic statistics can appear while reference statistics are still loading.
- Refine card action menus and use theme-aware rounded tag styling.

### Fixes

- Fix the first tap sometimes failing in mobile card and filter menus, including floating menus.
- Check the selected Trash recovery copy before restoring. If it has changed or cannot be verified, stop and ask for a refresh.
- Resume Monthly archive updates after configuration becomes available or background processing fails, and avoid overwriting archives moved or replaced during generation.
- Restore reference summaries and relation details for Memos using supported legacy block-anchor formats.
- Treat an incomplete or invalid date expression as a text search for the whole input, instead of leaving the previous search in place.
- Keep reference statistics unavailable until their results are complete, and avoid replacing current views with outdated asynchronous results.
- Prevent a read-only check for legacy migration at startup from blocking ordinary Memo edits; any required cleanup still waits for safe access.

### 新增功能

- **被引用筛选：** 在桌面和移动端浏览被其他 Memo 引用的记录，并可结合搜索和日期选项使用。

### 改进

- **常用标签：** 周、月、年统计最多展示 10 个标签。每条 Memo 对直接标注的每个完整标签计数一次，因此 `#project` 和 `#project/a` 分别统计。点击标签可查看直接标注该标签的记录；侧栏标签筛选仍包含子标签。
- 优化移动端 Composer 的打开、键盘定位及关闭后重新打开的过渡，关闭时保留草稿。
- 刷新列表和切换筛选时，更稳定地保留已加载的卡片图片；移动端搜索结果刷新或展开时保留阅读位置。本地附件变化时更新受影响的预览。
- 减少隐藏页面和卡片移除后的不必要处理；分阶段准备记录统计，让基础统计可以在引用统计加载期间先行显示。
- 调整卡片操作菜单，并使用跟随主题的圆角标签样式。

### 修复

- 修复移动端卡片和筛选菜单首次轻触有时不生效的问题，包括浮动菜单。
- 恢复前核对选中的回收站副本；副本已变化或无法验证时停止恢复，并提示刷新。
- 配置恢复可用或后台处理失败后重新协调月度归档，并避免覆盖生成期间被移动或替换的归档。
- 恢复支持的旧版块锚点格式对应的引用摘要和关联详情。
- 输入不完整或无效的日期表达式时，将整段输入作为文字搜索，避免继续显示上一次搜索结果。
- 等待被引用统计完整后再提供对应结果，并避免过期的异步结果覆盖当前页面。
- 避免启动时的旧版迁移只读检查阻塞普通 Memo 编辑；需要清理时仍会等待安全执行。
