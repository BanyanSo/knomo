## Knomo 1.14.8

### Improvements

- Use a more compact time-prefix format when a Memo's Markdown content and block reference can be preserved safely. Existing formats remain readable.
- Keep loaded card images and visible counts more stable as Memo lists, filters, search results, and relation views update.
- Preserve expanded pages and reading position more reliably when Memos are edited or Daily notes change, including in mobile search and the time buoy.
- Respect Obsidian's excluded-file rules in Composer tag suggestions. Changes to those rules update an open suggestion list; sidebar tag display remains unchanged.
- Preserve the selection and scroll position in tag suggestions as the list updates.
- Show a loading indicator in search and filter summaries while result counts are being calculated, then update the count when it is ready on desktop and mobile.
- Improve loading and empty states for filtered results and Random Reunion; keep the previous Random Reunion results visible while another group loads.
- Keep the loaded range when the referenced filter refreshes, and preserve Random Reunion entries when only the Daily note's frontmatter changes after a Memo edit.

### Fixes

- Preserve block references and Markdown structure when editing Memos, including supported legacy paragraph and header anchors. Stop the edit if the reference cannot be preserved safely.
- Prevent task changes from being applied to an outdated Memo; refresh and select it again if the source has changed.
- Keep Daily parsing, Monthly archives, and Trash recovery consistent for supported Memo formats and block references.
- Avoid displaying stale counts or replacing current view state with outdated results during refreshes.
- Keep available tag suggestions when file metadata or exclusion rules are temporarily unavailable, and refresh them when access recovers.
- Keep the cursor on the same line when completing a tag before a line break.
- Prevent the mobile Composer entrance from being clipped on WebViews without support for the clipping effect, and preserve the host theme's navigation bar styling.
- Keep affected cards readable while external Daily changes are checked, and pause their actions until the current content is confirmed.

### 改进

- 在能够安全保留 Markdown 正文和块引用时，使用更紧凑的 Memo 时间前缀格式；原有格式仍可读取。
- 优化 Memo 列表、筛选、搜索结果和关联视图更新时的显示，更稳定地保留已加载图片和可见数量。
- 编辑 Memo 或 Daily 笔记发生变化时，更稳定地保留已展开的分页范围和阅读位置，包括移动搜索和时间浮标。
- Composer 标签候选遵循 Obsidian 的文件排除规则；规则变化时，已打开的候选列表也会更新，侧栏标签显示保持原有行为。
- 标签候选列表更新时保留选中项和滚动位置。
- 桌面和移动端的搜索及筛选摘要在统计结果数量时显示加载状态，完成后更新数量。
- 优化筛选结果和随机重逢的加载及空结果状态；随机重逢加载新一组时保留之前的结果。
- 被引用筛选刷新时保留已加载范围；编辑 Memo 后，如果 Daily 只有 frontmatter 发生变化，保留随机重逢中的记录。

### 修复

- 编辑 Memo 时保留块引用和 Markdown 结构，包括支持的旧版段落及时间行锚点；无法安全保留引用时停止编辑。
- 避免将任务勾选应用到过期的 Memo；源内容变化时需刷新后重新选择。
- 保持 Daily 解析、月度归档和回收站恢复对受支持的 Memo 格式及块引用的处理一致。
- 避免刷新时显示过期数量，或让过期结果覆盖当前视图状态。
- 文件元数据或排除规则暂时不可用时保留可用的标签候选，恢复后更新列表。
- 在换行前补全标签时，让光标停留在原行。
- 修复不支持裁剪效果的 WebView 中移动端 Composer 入场时可能被裁切的问题，并保留宿主主题的导航栏样式。
- 核对外部 Daily 变更期间保持受影响卡片可读，确认当前内容前暂停这些卡片的操作。
