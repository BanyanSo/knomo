## Knomo 1.15.0

### New features

Find “Set as Beacon” and “Star” together in the Memo card menu.

#### Beacon

- Pin one Memo to the top of the default Memo list. To change the Beacon, set another Memo as the Beacon. To unpin it, choose “Remove from Beacon” from its card menu.
- The pinned card shows a lighthouse. If the same Memo also has a Time Buoy, both icons appear.
- The Beacon stays with the same Memo when you edit its time or rename its daily note. If Knomo can no longer find the Memo, it prompts you to set the Beacon again. Changing the Beacon also preserves loaded pages and your reading position more reliably.

#### Favorites

- Star Memos from their card menus and open Favorites from the sidebar or view menu. Search or filter your starred Memos and see the total number of matches, including results beyond the loaded pages.
- Favorites distinguishes an empty search from saved Memos that are temporarily unavailable. Cards stay steadier when you star a Memo, and removing a star from Favorites is less likely to shift your reading position.
- Record Stats shows how many starred Memos were written in the selected week, month, or year. Select the count to see those Memos.
- The Favorites file lives in the Knomo folder. If you change that folder, Knomo tries to move the file and tells you if the move is incomplete.

### Improvements

- Search for several keywords at once by separating them with spaces. For example, `project review` finds Memos containing both words in any order. Use double quotes to search for a continuous phrase, and combine keywords, phrases, and a date.
- Searching within Things, Favorites, Referenced, or a Record Stats detail keeps the original scope. An added date narrows that scope. The result summary shows the search conditions and indicates when date ranges do not overlap.
- Choose “Search date as text” in the result summary to look for a recognized date as text. Incomplete or invalid dates search the entire input as continuous text and show “Searched as typed”. Selecting a quick date replaces a valid typed date while keeping other keywords.
- Record Stats now shows how many Memos in the selected period appear in Things. Select the count to see those Memos.
- When you change the Knomo folder, Knomo rebuilds monthly archives in the new location from your daily notes. It also tries to move the Trash file and tells you if the move is incomplete.
- Loaded pages and your reading position stay more stable when you edit a Memo or copy its block link.

### Fixes

- Protect unsaved edits in daily notes during Memo writes and recheck the target daily note before deleting or restoring a Memo.
- Restore Memos from Trash even when a link or code contains text that looks like a block ID. Knomo stops the restore if the target daily note already has the same block ID as the Memo being restored.

### Upgrade note

If you still need to import Trash from Knomo 1.2.9 or earlier, use a version that offers legacy Trash recovery, such as 1.14.8, before upgrading. Previously imported records remain available in Trash.

### 新增功能

「设为灯标」和「拾星」在 Memo 卡片菜单的同一组。

#### 灯标

- 将一条 Memo 置顶在默认列表。要更换灯标，直接将另一条 Memo 设为灯标。要取消置顶，在原卡片菜单选择「移出灯标」。
- 置顶卡片会显示灯塔图标。同一条 Memo 也有时光浮标时，卡片会同时显示两个图标。
- 修改 Memo 的时间或重命名所在日记后，灯标仍指向原来的 Memo。找不到原 Memo 时，Knomo 会提示重新设置。更换灯标时，列表也能更稳定地保留已加载的内容和阅读位置。

#### 拾星集

- 在卡片菜单选择「拾星」，即可将 Memo 收进拾星集。从侧栏或视图菜单打开拾星集后，可以搜索、筛选并查看匹配总数。总数包含尚未加载的结果。
- 没有匹配结果和部分拾星暂时无法显示时，各有对应提示。拾星时卡片显示更稳定，在拾星集取消拾星时也更容易留在原来的阅读位置。
- 「记录统计」会显示所选周、月或年内写下的已拾星 Memo 数量。点击数字可查看对应的 Memo。
- 拾星文件保存在 Knomo 文件夹中。更改文件夹位置时，Knomo 会尝试搬迁拾星文件，并在搬迁未完成时提示。

### 改进

- 搜索支持用空格组合多个关键词。例如，`项目 复盘` 会找到同时包含两个词的 Memo，顺序不限。给短语加双引号可以查找连续文字，也可以将关键词、短语和日期组合搜索。
- 从勾事记、拾星集、被引用或记录统计明细发起搜索时，会保留原有范围。追加的日期会进一步缩小范围。结果摘要会显示搜索条件，并在日期范围不重叠时给出提示。
- 日期被识别后，可在结果摘要中选择「按文字搜索」。日期尚未输入完整或不合法时，整条输入会按连续文字搜索，并显示「已按原文搜索」。选择快捷日期时，会替换已输入的有效日期并保留其他关键词。
- 「记录统计」新增所选时段的勾事记数量。点击数字可查看对应的 Memo。
- 更改 Knomo 文件夹位置后，Knomo 会根据日记在新位置重建月度归档，并尝试搬迁回收站文件。搬迁未完成时会提示。
- 编辑 Memo 或复制块链接时，更稳定地保留已加载的内容和阅读位置。

### 修复

- 写入 Memo 时保护日记里尚未保存的编辑。删除或恢复 Memo 前，会再次核对目标日记。
- 从回收站恢复时，链接或代码中形似块 ID 的文字可以随 Memo 一起恢复。如果目标日记已有与待恢复 Memo 相同的块 ID，Knomo 会停止恢复。

### 升级提示

如果仍需导入 Knomo 1.2.9 或更早版本的回收站，请在升级前用仍提供「恢复旧版回收站」的版本完成导入，例如 1.14.8。此前已导入的记录仍可在回收站中使用。
