## Knomo 1.15.0

### New features

- **Beacon.** Choose “Set as Beacon” from a Memo's card menu to pin it to the top of the default Memo list. You can switch the Beacon to another Memo or remove it from the card menu. When the same Memo is a Beacon and a Time Buoy, its card shows both icons.
- **Favorites.** Choose “Star” from a Memo's card menu to save it to Favorites. Open Favorites from the sidebar or view menu to browse starred Memos and narrow the list with search or filters.

### Improvements

- Group Beacon and Star actions together in the card menu. Favorites gives more specific feedback when no Memos match or when some saved items are temporarily unavailable.
- The Knomo folder now stores monthly archives, Trash, and Favorites. When you change the folder, Knomo rebuilds monthly archives from daily notes in the new location, attempts to move the Trash and Favorites files, and reports any incomplete move.
- Keep loaded pages and reading position more stable when editing Memos, copying block links, changing the Beacon, or unstarring a Memo in Favorites.

### Fixes

- Keep the Beacon tied to the selected Memo when its time changes or its daily note is renamed. If Knomo can no longer locate the Memo, it prompts you to set the Beacon again.
- Protect unsaved daily note edits from overlapping Memo writes, and recheck the target daily note before deleting or restoring a Memo.
- Restore Memos from Trash when ordinary references or code merely contain text that looks like a block ID. Actual duplicate block IDs still stop the restore.

### 新增功能

- **灯标。** 在卡片菜单选择「设为灯标」，即可将一条 Memo 置顶在默认列表。可随时换成另一条 Memo，也可从卡片菜单移出灯标。同一条 Memo 兼具灯标和时光浮标时，卡片会同时显示两个图标。
- **拾星集。** 在卡片菜单选择「拾星」，即可把 Memo 收进拾星集。从侧栏或视图菜单打开拾星集，可浏览、搜索和筛选已拾星的 Memo。

### 改进

- 卡片菜单将灯标和拾星操作归在一组。拾星集会分别提示没有匹配结果、部分拾星暂时无法显示等情况。
- Knomo 文件夹现在用于存放月度归档、回收站和拾星文件。更改位置后，Knomo 会根据日记在新位置生成月度归档，尝试搬迁回收站和拾星文件，并提示未完成的搬迁。
- 编辑 Memo、复制块链接、更换灯标或在拾星集中取消拾星时，更稳定地保留已加载的分页和阅读位置。

### 修复

- Memo 时间变化或所在日记改名后，灯标继续指向原来选中的 Memo。找不到原 Memo 时，会提示重新设置灯标。
- 避免同时进行的 Memo 写入覆盖日记中尚未保存的编辑。删除或恢复 Memo 前，会再次核对目标日记。
- 从回收站恢复时，普通引用或代码中形似块 ID 的文字可以随 Memo 一起恢复。如果目标日记已有相同的实际块锚点，则停止恢复。
