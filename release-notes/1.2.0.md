## Knomo 1.2.0

### New features

* Added **Time buoy**. Add `@YYYY-MM-DD` to a memo by typing it directly or using the composer date picker, then revisit it in Today, Upcoming, and Past views.
* Added a local, removable, and rebuildable Time buoy index. Date markers remain in the memo's Markdown content, and index maintenance never replaces the Daily Note as the source of truth.

### Improvements

* Improved progressive card loading, in-place card updates, and recovery tools for derived index files.
* Improved WikiLink suggestions with explicit listbox relationships, active-option state, and expanded-state announcements for assistive technologies.

### Fixes

* Fixed concurrent plugin-data writes that could overwrite settings, Random revisit review state, or Shuffle day history.
* Fixed concurrent memo mutations overlapping with maintenance operations by serializing user-initiated memo writes.

---

### 新功能

* 新增 **时光浮标**。可以直接输入或通过输入框日期选择器为 memo 添加 `@YYYY-MM-DD`，并在“今日”“待浮现”“往日”视图中回看。
* 新增可删除、可重建的本地时光浮标索引。日期标记会保留在 memo 的 Markdown 正文中，索引维护不会替代作为正文主存储的 Daily Note。

### 改进

* 改进渐进式卡片加载、卡片原位更新，以及派生索引文件的恢复工具。
* 改进 WikiLink 联想的无障碍支持，补充列表框关联、当前选项状态和展开状态提示。

### 修复

* 修复并发写入插件数据时，设置、随机重逢回看状态或往日漫游历史可能互相覆盖的问题。
* 修复用户发起的 Memo 写入可能与维护操作重叠的问题，现在会串行执行 Memo 变更。
