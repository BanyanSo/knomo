## Knomo 1.2.1

### Improvements

* Replaced native browser confirmations for maintenance operations and permanent deletion with a consistent, keyboard-accessible Knomo dialog that preserves focus and adapts to mobile screens.
* Simplified everyday interactions: moving a memo to Trash no longer requires an extra confirmation, and collapsing or dismissing the composer keeps the current draft without interrupting the flow.
* Improved Time buoy refreshes so previously loaded content stays visible and unchanged results do not trigger unnecessary rerenders.
* Improved Markdown rendering lifecycle management so replaced, cleared, or stale card renders release their resources promptly.
* Removed obsolete service wrappers and test-only production APIs, and aligned the affected tests with the current production paths.

### Fixes

* Fixed deleted memos remaining in or returning to Time buoy views because their derived date entries were not removed correctly.
* Fixed Time buoy views not refreshing immediately when a visible memo is deleted.
* Fixed partial multi-image imports leaving orphaned attachments when a later image fails to save.

---

### 改进

* 将维护操作和永久删除所使用的浏览器原生确认框替换为统一的 Knomo 弹窗，支持键盘操作、焦点恢复和移动端布局。
* 简化日常操作：将 memo 移入回收站不再额外确认，收起或退出输入框时会保留当前草稿，不再打断记录流程。
* 改进时光浮标刷新：已加载内容在后台刷新时保持可见，结果未变化时不再触发多余渲染。
* 改进 Markdown 渲染生命周期管理：卡片渲染被替换、清理或过期时会及时释放相关资源。
* 移除已废弃的服务包装方法和仅供测试使用的生产接口，并将相关测试迁移到当前生产路径。

### 修复

* 修复已删除 memo 因派生日期记录未正确清理，仍留在或重新出现在时光浮标视图中的问题。
* 修复删除当前可见 memo 后，时光浮标视图未立即刷新的问题。
* 修复批量导入多张图片时，后续图片保存失败会遗留孤立附件的问题。
