## Knomo 1.2.5

### Improvements

* Improved WikiLink suggestion keyboard navigation by automatically keeping the selected candidate visible as the selection moves.
* Updated Markdown syntax handling and styles for compatibility with Obsidian 1.13.4.

### Fixes

* Fixed missing bottom spacing on Time buoy pages across desktop and mobile layouts.

---

### 改进

* 改进 WikiLink 联想的键盘导航，在移动选项时自动保持选中项可见。
* 适配 Obsidian 的 1.13.4 版本一些 markdown 语法、样式更新。

### 修复

* 修复桌面端和移动端的时光浮标页面缺少底部留白的问题。
