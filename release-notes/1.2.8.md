## Knomo 1.2.8

### Improvements

* Improved mobile startup and browsing performance by loading recent Memos first, fetching older history on demand, and loading only the required monthly periods for date, tag, and statistics filters.
* Added a local Memo summary cache so counts, tags, images, and word statistics remain available without loading every Memo into memory.
* Improved tag suggestions and tag display updates with an incremental vault tag index.
* Deferred expensive Time buoy index rebuilding on mobile until the full Time buoy view is opened.

### Fixes

* Fixed stale mobile header bindings and settings-page status output after dynamic UI rerenders.
* Fixed recent startup scans doing unnecessary full-vault work and improved consistency when merging newly loaded history with updated or deleted Memos.

---

### 改进

* 改进移动端启动和浏览性能：优先加载近期 Memos，按需加载更早历史，并在日期、标签和统计筛选时仅加载所需月份。
* 新增本地 Memo 汇总缓存，无需将全部 Memo 加载到内存，即可提供数量、标签、图片和字数统计。
* 新增增量 Vault 标签索引，提升标签联想和标签展示更新效率。
* 移动端延迟执行耗时的时光浮标索引重建，仅在首次打开完整时光浮标视图时触发。

### 修复

* 修复动态界面重新渲染后，移动端标题事件绑定和设置页状态输出可能失效的问题。
* 修复近期启动扫描执行不必要的全 Vault 工作，并改进历史 Memo 按需载入时与已更新或已删除 Memo 的合并一致性。
