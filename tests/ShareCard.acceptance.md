# Share Card 实机验收

本清单自包含；实现、测试和构建不需要本地 `docs/`。自动化入口为
`ShareCard.test.ts`、`ShareCardResources.test.ts`、`ShareCardLayout.test.ts`、
`ShareCardTypographyLayout.test.ts` 和 `ShareCardModalLayout.test.ts`。
浏览器测试沿用项目的 `KNOMO_LAYOUT_PLAYWRIGHT` / `KNOMO_LAYOUT_BROWSER` 配置，
在 `.tmp/share-card-samples/` 生成三种内容 × 四种模板的十二张代表性 PNG，以及字体、对齐和弹窗样张。
样张使用测试夹具及本地生成的图形，不读取用户其他 Memo。

## 当前实现边界

- `paper`（素笺）、`calendar`（日历）、`editorial`（观照）、`ink`（墨笺）；默认 `paper`，不持久化模板偏好。
- 390 CSS px 固定版心、2× PNG，不截断、不分片、不自动缩小字号。
- 四套模板末尾均独立居中显示一次纯文字「Knomo」，12 CSS px、常规字重、模板品牌色；上方间距 24 px，下方复用 36 px 底部留白。标志进入实际 PNG，正文中已有的同名文字照常保留。
- 观照固定使用随插件打包的默认封面，正文图片保持原顺序；日历显示日期头，其他模板只显示日期，不附加 Memo 的分钟/秒时间或来源元信息。
- 正文字体、界面字体、等宽字体和正文字号取自打开会话时的宿主设置；本地可读取字体随画布嵌入，不下载远程字体。只有实际使用的字体无法加载时才阻断生成。
- PNG 最大边长 16384 px；移动端最多 1200 万输出像素，桌面端 3200 万。
- 单资源最多 32 MB；已缓存位图加当前资源原始解码像素移动端最多 2400 万、桌面端 6400 万。
  常见 PNG/JPEG/GIF/WebP/BMP 在解码前校验头部尺寸，所有资源解码后再校验。
- 资源在会话内固定为静态 PNG；宽度超过 780 px 时等比缩至输出所需宽度。
- 表格内容完整换行；非空单元格不足 44 CSS px 或其他内容溢出时拒绝输出。
- 支持常用 Markdown、WikiLink、任务、展开的 Callout 及静态图片。
  HTML、数学公式、脚注、动态查询/图表、笔记/音视频/PDF 嵌入会说明类型并拒绝输出。
- 远程图片只直接请求正文中的 HTTP(S) 地址，使用 CORS、无凭证、无代理，20 秒超时。
- 预览直接显示实际 PNG。分享与复制只使用当前就绪版本，在点击栈内调用。
- 复制成功、系统分享接口完成、发起桌面下载和 Vault 文件写入成功均不显示提示文案；取消系统分享不显示错误。
- 输出失败显示“图片输出失败，请重试或使用其他操作。”，保留已生成图片以供重试。
- 无直接输出接口时明确提示；移动端真实输出失败后也提供显式保存至 Vault 根目录的替代操作；此操作不等于保存相册，
  也不代表该设备已验证便捷的跨应用分享。文件重名使用新名称，创建失败不覆盖。

以上是保守软件限制，不能作为某款设备的硬件极限或稳定性保证。

## 每个平台必须记录的证据

在 Obsidian Desktop、iOS、Android 分别记录宿主/系统版本与下列实际结果。
浏览器模拟、API 能力探测和自动化 PNG 测试均不替代这些证据。

1. 先用短 Memo 验证一条真实输出路径：接收应用获得 PNG、图片剪贴板粘贴成功，
   或桌面下载后能打开文件。移动端记录实际可用接口；取消分享无错误，拒绝权限可重试。
2. 检查十二张代表性样张的实际手机阅读宽度，并在常用接收应用打开一张长图。
   文字、Emoji、图片比例、尾部内容完整；记录接收应用是否压缩图片。
   确认末尾 Knomo 文字标志清晰、仅添加一次，模板切换后颜色正确；短文、纯图片、含来源及长图中均不遮挡内容，预览与分享、复制、保存取得的 PNG 一致。
3. 检查原 Memo 无 blockId、同文不同 occurrence、来源引用、分钟/秒时间、
   图文交替、同图两次、纯图片、嵌套图片、Callout、任务、代码及表格。
4. 观照在有图和无图时均显示同一默认封面，正文首图、中段、列表及引用图片均保留原位置；日历日期头只出现一次。
   检查高亮中的引用式图片和链接、转义美元文本，以及 Callout 标题与正文的字重分离。
5. 亮/暗及代表性第三方主题下，模板配色保持固定，字体和字号沿用会话开始时的宿主设置；320 px、手机横屏、大字体下，
   关闭、模板与输出操作可达，预览独立滚动，安全区及宿主导航不遮挡操作。
6. 时间流、搜索、标签、随机重逢和关联页可进入；Trash 无入口。
   关闭后保留原位置和搜索状态，键盘焦点回到原卡片菜单。
7. 快速切换模板、关闭时仍在加载、原 Memo 在分享期间修改、缺失图片、
   远程图片失败、超限和输出失败均保留正确状态；旧结果不覆盖新选择。
8. 显式选择 Vault 保存时，确认真实目录及重名行为；尤其在 Android 上，
   验证用户能否取得该文件继续分享。不能取得时不能视为平台交付完成。

尚无本任务的 Obsidian 桌面、iOS 或 Android 实机验收证据。
